这是博客的第一篇文章，先把坑占了。

## 这里会写什么

- **随笔**：记录学习和做项目时踩的坑、想通的事，比朋友圈正经一点，比日记随意一点。
- **笔记**：技术笔记放在本地，不上公开仓库 —— 这类东西成型了、值得分享时，我再整理成文章发出来。

## 这个站是怎么搭的

- 静态站点生成器用的是 [Astro](https://astro.build)，模板基于 [astro-cactus](https://github.com/chrismwilliams/astro-cactus) 改的。
- 文章直接在 VSCode 里写 Markdown，`git push` 之后 GitHub Actions 自动构建部署到 GitHub Pages。
- 评论区用的是 [Giscus](https://giscus.app)，数据存在 GitHub Discussions 里，没有后端服务器。

对一个静态博客来说，这套流程的好处是：写东西的门槛降到了最低 —— 打开编辑器、写、推上去，完事。

## 为什么要写博客

大三，主线是考研，方向是计算机视觉。很多东西当时觉得懂了，过两个月再看就是一团浆糊 —— 写下来是检验自己有没有真懂的最好办法。

就这样，后面见。
